# Vehicle Images Directory

Place your car images (JPG, PNG, WebP) directly into this folder.

### How to use your images:
Any image added here is automatically available on the website at:
`/cars/<filename>`

**Example:**
If you save an image as `2024-toyota-prado.jpg` in this folder:
- **Local / Relative URL:** `/cars/2024-toyota-prado.jpg`
- **Live Website URL:** `https://leeautox.com/cars/2024-toyota-prado.jpg`

You can paste this path into the "Main Image URL" or "Gallery Images" inputs in the Admin Backend (`/bkend`) or directly in Firestore.
