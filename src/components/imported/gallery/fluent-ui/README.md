# Fluent UI React 交互示例

UI Moments 为 Microsoft Fluent UI React 编写了 51 个互动示例，覆盖表单、导航、反馈与数据展示。组件版本固定为 `@fluentui/react-components@9.75.2`，构建依赖由锁文件固定。

按[项目 README](../../README.zh-CN.md#本地运行) 构建站点后，在图鉴首页搜索 `Fluent UI` 或示例名。在本目录运行 `npm run dev` 可迭代组件。开发入口可使用 `?sample=drawer` 选择示例。

## 示例清单

- **控件** Drawer、Teaching Popover、Toast、Accordion、Tri-state Checkbox、Searchable Combobox、Multi-select Dropdown、View Menu、Confirmation Dialog、Preview Switch、Zoom Slider、Spin Button、Project Tabs、Star Rating、File Tree、Swatch Carousel、Progress Bar
- **表单** Form Field、Text Input、Textarea、Info Label、Radio Group、Search Box、Native Select、Color Picker、Swatch Picker、Tag Picker
- **导航与数据** Avatar Group、Breadcrumb、Split Button、Link、Selectable List、Navigation Rail、Overflow Menu、Sortable Data Grid、Formatting Toolbar、Virtualized List
- **反馈** Action Button、Compound Button、Toggle Button、Selectable Card、Info Button、Message Bar、Alert、Interactive Popover、Skeleton Loading State、Spinner Loading State、Dismissible Tags、Interaction Tag、Tooltip、Inline Drawer
