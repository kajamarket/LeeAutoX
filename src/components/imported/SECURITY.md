# 安全策略 / Security Policy

维护范围包括 `main` 分支和[线上站点](https://guanmo-ai.github.io/ui-moments/)。主题、语言、列数和收藏偏好保存在当前浏览器中。

发现漏洞时，请使用 GitHub [私密漏洞报告](https://github.com/guanmo-ai/ui-moments/security/advisories/new)，并尽量附上受影响的页面或版本、复现条件和可能影响。漏洞报告请保持私密，直至与维护者协调披露。

The `main` branch and the [live site](https://guanmo-ai.github.io/ui-moments/) are supported. Theme, language, column count, and favorites are stored in your browser.

Use GitHub's [private vulnerability reporting form](https://github.com/guanmo-ai/ui-moments/security/advisories/new) for security issues. Include the affected page or version, reproduction conditions, and potential impact. Keep the report private while coordinating disclosure with the maintainers.
